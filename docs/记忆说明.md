# 记忆（长期记忆插件）

爱弥斯会记住**值得长期记住的事**，并且像人一样慢慢忘掉不重要的。

设计参考 [SurfCore](https://github.com/Mieksido/surfcore) 的记忆卡（`src/memory-card.js`）：
不是把聊天记录全塞进上下文，而是抽取成一条条记录，按清晰度阶梯衰减。

## 它记什么

- **人物**：谁是谁、称呼、关系、性格、明确说过的偏好
- **事件**：正在做的事（备考、找工作、生病）、约定、承诺、重要日子
- **梗**：群里反复出现的梗、专属称呼

不记：寒暄、一次性情绪、复述原话、密码/手机号这类敏感信息（入库前会脱敏）。

## 遗忘规则

| 阶段 | 触发 | 表现 |
|---|---|---|
| 清晰 | 最近 1 天 / 永久锚点 | 完整出现在对话里 |
| 清楚 | 最近 7 天内 | 完整出现 |
| 模糊 | 7 天后逐步降档 | 仍然出现，标注「模糊」 |
| 只剩印象 | 更久 | 偶尔出现 |
| 遗忘 | 超过 60 天且不重要 | 不再注入（文件里留档） |

- **永久锚点**：主人说过的话、`/记住` 手动记的、重要度 ≥ 65 的，最差也保持「清楚」
- **复习效应**：一条记忆被再次提到，会刷新时间、从模糊变回清楚

## 指令

| 指令 | 作用 |
|---|---|
| `/记忆` | 看这个会话相关记忆数量 + 最近 5 条 |
| `/记住 阿伟在准备考研` | 手动记一条（永久） |
| `/忘记 考研` 或 `/忘记 a1b2c3d4` | 按关键词或 id 删除 |
| `/记忆清空` | 清空全部（管理员） |

## 自动抽取

- 每个会话（每个群 / 私聊）累积 **20 条消息** 触发一次
- 同一会话两次抽取至少间隔 **15 分钟**
- 抽取走当前对话模型，要求只输出 JSON，最多 5 条
- 存 `astrbot_plugin_aemeath_memory/data/memory.json`

## 注入方式

对话时把「当前会话 + 全局」的记忆按清晰度、重要度排序，拼成 `<memory>` 块，
通过 `extra_user_content_parts` 注入（不和别的插件抢 system_prompt），默认上限 1200 字。

## 配置

| 键 | 默认 | 说明 |
|---|---|---|
| `enabled` | `true` | 总开关 |
| `autoExtract` | `true` | 自动抽取 |
| `extractEvery` | `20` | 累积多少条消息抽取一次 |
| `extractCooldown` | `900` | 同会话抽取最短间隔（秒） |
| `injectMaxChars` | `1200` | 注入字数上限 |
| `recentDays` | `7` | 最近几天至少「清楚」 |
| `forgetAfterDays` | `60` | 多少天后彻底遗忘 |
| `maxRecords` | `500` | 最多保留条数（永久记忆不淘汰） |

## 已知边界

- 记忆是**按会话隔离**的：A 群的记忆不会出现在 B 群，只有 `global`（主人/手动）的到处都在
- 抽取依赖模型质量，模型抽歪了用 `/忘记` 删掉即可
- 关掉插件不会删数据；数据在 `data/memory.json`，可以直接备份


## 历史回填

面板 → 左侧「长期记忆」→ **回填历史**（默认最近 7 天）：

- 读取日记插件的历史记录 `daily/<日期>/<群号>.jsonl`（每个群每天一个文件）
- 每个「群 × 天」抽一次：模型最多给出 6 条长期信息（人物/事件/梗）
- 结果写进对应群的记忆（`group:<群号>`），重要度不低于 50
- 已处理过的「群 × 天」记在 `backfill_done.json`，重复点不会重复抽
- 进度在面板上实时显示，跑完提示新增多少条

命令行等价：`/记忆回填 7`（管理员，在群里或私聊发）。

## 面板管理

左侧「长期记忆」页面可以：

- 看统计：总数、清晰、模糊、已遗忘、全局
- 搜索记忆内容
- 逐条删除（×）—— 删掉就是真的忘了
- 回填历史 / 清空全部（会留 `.bak`）

面板改完 `memory.json` 后，插件按文件修改时间自动热加载，不用重启。
