# 设置面板（dashboard）

一个跑在服务器上的小型前后端，用来**直接改项目里所有插件的配置**，不用再进 AstrBot WebUI 或手动编辑 JSON。

## 访问方式

面板默认只监听服务器本机 `127.0.0.1:8610`，不对外开端口。

服务器已经接入 **Tailscale 私有网络**，所以下面命令里的地址用内网 IP：

```
<TAILSCALE_IP>     （节点 qqbot-ecs）
```

公网 `<SERVER_IP>` 只在没装 Tailscale 的临时场合用（需要安全组放行 22）。

### 方式零：Tailscale 内网（当前采用）

服务器已加入 Tailscale，节点名 `qqbot-ecs`：

- 电脑/手机装 [Tailscale](https://tailscale.com/download) 并用同一账号登录，任何网络下都能连 `<TAILSCALE_IP>`
- 家里宽带 IP 变了也不影响（这就是换掉「安全组填自己 IP」的原因）
- 安全组里的 22 端口规则可以**全部删掉**，公网扫不到 SSH


### 方式一：本机 SSH 隧道（推荐，不需要 agent）

**双击 `deploy\打开面板.bat`** 就行：它会开一个隧道窗口并自动打开浏览器。关掉那个窗口即断开。

手工命令等价于：

```powershell
ssh -N -i deploy\keys\aliyun_ed25519 -L 8610:127.0.0.1:8610 ecs-user@<TAILSCALE_IP>
```

然后浏览器打开 <http://127.0.0.1:8610/>，首次会要求输入 token。

同理，AstrBot 自己的 WebUI（6185）和 NapCat WebUI（6099）也能这样映射：

```powershell
ssh -N -i deploy\keys\aliyun_ed25519 -L 6185:127.0.0.1:6185 -L 6099:127.0.0.1:6099 ecs-user@<TAILSCALE_IP>
```

### 方式二：公网直连（要改绑定 + 安全组，风险自负）

适合手机/平板随时开，但**必须把来源 IP 限死**：

1. 服务器上让面板监听所有网卡：

   ```bash
   sudo systemctl edit qqbot-dashboard   # 或在 /etc/systemd/system/qqbot-dashboard.service 里加一行
   # [Service]
   # Environment=DASH_HOST=0.0.0.0
   sudo systemctl daemon-reload && sudo systemctl restart qqbot-dashboard
   ```

2. 阿里云控制台 → 安全组 → 入方向，添加 `8610/tcp`，**授权对象填你自己的公网 IP**（`1.2.3.4/32`），不要写 `0.0.0.0/0`

3. 浏览器访问 `http://<SERVER_IP>:8610/`（仅在没装 Tailscale 时；装了就删掉这条规则）

注意：这是 HTTP 明文，token 会以明文经过网络；运营商/公共 Wi-Fi 下不建议。想稳妥就再套一层 nginx + HTTPS + Basic Auth，或者用方式三。

同理 NapCat 的 6099 也能这样开，但 NapCat WebUI 一旦暴露风险更高（能直接操作 QQ 登录），强烈建议只走隧道或 VPN。

### 方式三：组内网（推荐长期方案）

装 [Tailscale](https://tailscale.com/)（免费档够用）：服务器和你的手机/电脑各登录一次，之后直接访问服务器的 Tailscale IP（如 `http://100.x.y.z:8610/`），不碰公网、不用改安全组，手机也能用。

面板已经在 `DASH_HOST=0.0.0.0` 时也能正常跑，配合 Tailscale 的私有网段即可。

## token

token 在服务器上：

```bash
sudo cat /opt/qqbot-dashboard/token
```

浏览器会记住 token，下次不用再输；换浏览器或清缓存后重新输入即可。

## 能做什么

| 功能 | 说明 |
|---|---|
| 插件列表 | 自动读取 `/opt/astrbot/plugins/*/_conf_schema.json`，左侧列出所有插件 |
| 改配置 | 按 schema 自动生成表单（布尔=勾选框、数字=数字框、text=多行），保存即写入 `/opt/astrbot/data/config/<插件名>_config.json` |
| 群名单可视化 | 名单类配置（`watchGroups` / `commentGroups` / `feedGroups` / `feedBlockList` / `abstractOnlyGroups` 等）自动变成**标签块**：输入群号回车添加、点 × 移除，输入框带「已知群号」下拉提示（来自各插件配置 + 日记的 umo 记录） |
| 长期记忆 | 左侧「长期记忆」：统计、搜索、逐条删除、回填历史、清空；改动热加载到插件 |
| 活跃度调节 | 顶栏「活跃度」五档（安静/低调/正常/活跃/话痨），一键写入群聊插话插件的概率、冷却、最短字数；插件会热加载配置，**立即生效不用重启** |
| 群白名单 | 「爱弥斯·群白名单」插件排在列表最前，`whitelistGroups` 用标签块增删；保存后**立即生效**（插件按配置文件 mtime 重读），与 `/allow`、`/deny` 命令写的是同一字段 |
| 备份 | 每次保存前把旧配置复制为 `<文件>.bak` |
| 重启 AstrBot | 一键 `docker restart astrbot`，约 20 秒后恢复 |
| 查看状态 | 容器状态 + 内存/swap |
| 查看日志 | AstrBot 最近 200 行日志（自动去 ANSI 颜色） |

### 界面（v1.0 重构）

- **登录遮罩**：未存 token 时先显示令牌输入页，输入正确后进入控制台，token 只存浏览器 localStorage
- **左侧栏**：品牌 + 插件搜索框（按插件名/显示名/说明/配置键过滤）+ 插件列表，选中项左侧有一条 accent 竖线
- **主区**：插件标题、说明、元信息标签；配置项按类型分两列（长文本与群名单占满整行），项与项之间用发丝线分隔，不用卡片堆
- **底部动作条**：保存 / 重新加载 / 「有未保存的修改」提示；保存后 toast 提示需要重启
- **右侧抽屉**：状态与日志不再用弹窗，而是从右侧滑出；重启确认也在抽屉里完成
- **交互细节**：列表 stagger 入场、按钮按压缩放、开关滑块过渡、群号标签块新增/删除动画、加载骨架屏、空态与错误态、移动端单列布局
- 字体：Geist（界面）+ JetBrains Mono（数字、群号、日志），CDN 不可用时回退系统字体

## 生效规则

- 大部分插件配置**需要重启 AstrBot** 才生效（面板上的「重启 AstrBot」按钮即可）
- 少量插件在读取配置时才用新值，但重启最稳妥
- 保存失败会提示原因（比如数字填了非法字符）

## 安全

- 只监听 `127.0.0.1`，外网无法直接访问，必须走 SSH 隧道
- 所有 API 需要 `X-Token` 或 `?token=`，token 随机生成、权限 600
- 服务以 root 运行（需要 `docker restart` 权限），只读写配置目录

## 文件

| 路径 | 说明 |
|---|---|
| `dashboard/server.py` | 后端（仅标准库，无第三方依赖） |
| `dashboard/index.html` | 前端单页 |
| `dashboard/tests/test_server.py` | 后端小测试（配置读写、类型转换、BOM） |
| `deploy/qqbot-dashboard.service` | systemd 服务 |
| `deploy/tunnel-dashboard.ps1` | 本地隧道脚本 |

服务器上路径：`/opt/qqbot-dashboard/`，服务名 `qqbot-dashboard`。

## 常见问题

| 问题 | 处理 |
|---|---|
| 浏览器打不开 | 隧道没起：重新跑 `tunnel-dashboard.ps1`；或端口被占（换 `-LocalPort 18610`） |
| 一直提示 token 错误 | `sudo cat /opt/qqbot-dashboard/token` 重新复制；清除浏览器 localStorage 后刷新 |
| 保存后没变化 | 点「重启 AstrBot」，或手动 `docker restart astrbot` |
| 服务挂了 | `sudo systemctl status qqbot-dashboard` / `sudo journalctl -u qqbot-dashboard -n 50` |
