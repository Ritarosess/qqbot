# 爱弥斯机器人 · 指令与触发说明

> 适用：AstrBot v4.29.1 + 本仓库 `astrbot/plugins/` 下的自研插件
> 说明：AstrBot 自带指令和自研插件指令各管各的，互不冲突

---

## 一、AstrBot 内置指令（框架自带，非插件）

群里发送 `/help` 会列出这些指令，列表以 `AstrBot v4.29.1(WebUI: v4.29.1)` 开头。

| 指令 | 作用 | 说明 |
|---|---|---|
| `/name` | 给当前会话（UMO）设置显示名 | 只是别名，方便在 WebUI 里辨认，不影响功能 |
| `/new` | 新建一个对话 | 另起新会话，旧上下文保留但不再参与 |
| `/provider` | 查看 / 切换 LLM 供应商 | 一般仅管理员可用 |
| `/reset` | 清空当前对话的上下文 | 与 `/new` 的区别：`/reset` 清记忆，`/new` 另开会话 |
| `/sid` | 获取会话 ID 等信息 | 调试用（排查会话串号等） |
| `/stats` | 查看当前会话的 token 用量 | 判断上下文用量的最直接方式 |
| `/stop` | 停止正在执行的 agent 任务 | 机器人卡在长任务（点歌下载、联网搜索）时用来中断 |

**使用要点**

- 上下文会自动裁剪：单个会话 token 涨到模型上限时，AstrBot 会自动丢弃旧消息，所以聊久了"记忆"会变短
- 想要持久记忆请看 `日记` 插件：每天 23:30 把各群聊天合并成一篇日记落盘（`plugin_data/astrbot_plugin_aemeath_diary/`）
- 不建议让普通群友随意 `/reset`、`/new`（会清掉整个群共享的上下文），可在 WebUI 的**指令权限**里限制为管理员

### 掉线看门狗（管理员）

| 指令 | 作用 |
|---|---|
| `/掉线状态`（别名 `/看门狗`） | 查看 NapCat 在线状态、掉线原因、上次重启时间 |
| （自动） | 主机侧每 2 分钟检查：掉线先快捷登录，失败自动重启 NapCat 生成新二维码；恢复后私聊管理员「掉线 X 分钟已恢复」 |
| （自动） | 同时检查 AstrBot 容器是否还在跑：模型接口连续失败会让它整个退出，看门狗发现没在运行就 `docker start` 兜底 |

> 2026-10-27 排障记录：阿里云内网 DNS（100.100.2.136/138）短暂不响应 → 模型接口域名解析失败 → AstrBot 重试 5 次后抛出未捕获异常退出，同一时刻 QQ 会话也失效。现在 DNS 主用 `223.5.5.5 / 119.29.29.29`（阿里云内网 DNS 降为 fallback），并加了容器兜底拉起。


### 群管理（管理员）

| 指令 | 作用 |
|---|---|
| `/allow <群号>` | 把群加入白名单 |
| `/allow list` | 查看白名单 |
| `/deny <群号>` | 把群移出白名单（白名单为空时对所有群生效） |
| `/status` | 查看运行状态与白名单 |

> 白名单也可以在**设置面板**里改：插件「爱弥斯·群白名单」→ `whitelistGroups` 标签块，保存后**无需重启**（插件每次判断都会检查配置文件是否变化）。白名单存在插件配置里，`/allow` 会写回同一字段。

### 总结与日记

| 指令 | 作用 |
|---|---|
| `/summary` | 手动触发群聊总结（管理员，默认每天 21:00 自动） |
| `/日记 [YYYY-MM-DD]` | 查看某天日记（**仅管理员**，默认今天） |

### 记忆（长期记忆）

| 指令 | 作用 |
|---|---|
| `/记忆` | 看这个会话记住了多少、最近 5 条 |
| `/记住 阿伟在准备考研` | 手动记一条（永久，群/私聊各自作用域） |
| `/忘记 考研` | 按关键词或记忆 id 删除 |
| `/记忆清空` | 清空全部记忆（管理员） |

> 自动抽取：每个会话累积 20 条消息、且距上次抽取 ≥15 分钟时，交给模型抽 5 条以内的长期事实。
> 记忆会按 清晰→清楚→模糊→只剩印象→遗忘 逐级衰减；详见 [记忆说明](记忆说明.md)。

### 吃史仙人

| 触发 | 作用 |
|---|---|
| 群里发**合并转发** / **分享卡片** / **聊天截图（图片）** | 自动读取内容，按人设定级 Lv1-5 后评一句（不用 @） |
| `搬过去` / `转过去` / `喂一下` | 把最近一份内容搬到「好东西搬到哪个群」 |
| `这条也搬` / `这个也搬` / `再搬一次` / `这图搬走` | 口语触发：把最近一份内容搬到「好东西搬到哪个群」（管理员/ownerQQ） |
| `发我` | 搬到「说发我时搬给谁」的私聊 |
| `发给12345678` / `私聊12345678` | 搬到那个人的私聊 |
| `搬到859027267` / `群859027267` | 搬到那个群 |
| **@机器人 + 引用一条转发 + 搬过去** | 支持；被引用的转发会被解开读取后再搬（@ 机器人的普通对话仍走正常聊天） |
| 自动搬 | Lv ≥ `feedMinLevel`（默认 3）且概率命中（默认 0.3）时，静默搬到 feedGroups（跳过来源群，5 分钟内不重复，每小时上限 20） |
| 自动搬黑名单 | `feedBlockList` 里的 **QQ 号或群号**不会被自动搬史（名单群里的内容、名单用户发的内容都跳过）；手动搬不受影响 |
| 强制搬运 | **独立于等级/概率/黑名单**：「模型主题标签命中 `feedForceTags`（默认 `美少女,抽象,擦边`）」或「文本命中 `feedForceKeywords`」→ 直接搬（仍受去处/去重/小时上限约束）；评价照常 |
| 擦边 / R18 区分 | 模型标签互斥：**擦边**（轻度性感、暗示、露而不露）会被搬运；**R18**（色情、露骨）绝不搬运。万一同时出现，R18 优先 |
| R18 拦截 | **优先级最高**：模型打 `R18` 标签（`feedSkipTags`，默认 `R18`）或文本命中 `feedSkipKeywords` → **绝不搬运**（强制搬运也会被拦）；评语照发 |
| 权限 | 群里只有 `ownerQQ` 能叫搬；私聊不限制 |

> 配置项：观察白名单 `watchGroups`、评论白名单 `commentGroups`、搬史白名单 `feedGroups`、自动搬黑名单 `feedBlockList`、`feedPrivateTarget`、`feedMinLevel`、`feedProbability`、`summaryChars`、`dedupeMinutes`。

## 三、对话触发方式

- **@机器人** 后跟任意内容，走正常 LLM 对话（人设注入 + 上下文）
- 群内**唤醒词**开头（按 AstrBot 配置），或直接发指令
- 群聊**自动插话**：概率触发、60s 冷却，不 @ 也会接话；插话发送前有引用校验（对不上就不发）
- 私聊直接说话即可

## 五、权限与安全

- 管理员指令：`/allow` `/deny` `/status` `/voice` `/summary` `/emoji` `/水群` `/日记` `/写日记`
- 管理员账号在 AstrBot `admins_id` 中配置（当前：见 WebUI → 配置）
- 想让普通群友也能用的指令，可在 WebUI 的**指令权限**里放开；反之可收紧
- 机器人密钥只放服务器，不进 Git；NapCat 重启后需要重新扫码登录

## 六、上下文 / 记忆相关说明

| 机制 | 位置 | 说明 |
|---|---|---|
| LLM 会话上下文 | AstrBot 内存/会话存储 | token 上限后自动裁剪旧消息 |
| 每日总结 | `plugin_data/astrbot_plugin_aemeath_summary/daily/` | 每天 21:00 生成 |
| 每日日记 | `plugin_data/astrbot_plugin_aemeath_diary/` | 每天 23:30 生成，含原始 JSONL + 日记 Markdown + 合集 |
| 生活状态 | `dynamic_life_state` 插件 | 每天注入"当前时段在干嘛" |

> 备份建议：定期打包 `/opt/astrbot/data`（含插件数据、配置、日记），换机器直接还原。
